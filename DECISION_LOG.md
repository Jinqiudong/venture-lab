## 2026-10-01 — Use Venture Lab as the portfolio control center

**Decision:** Keep product code in separate repositories and use Venture Lab for ideas, portfolio status, shared workflow standards, and cross-project decisions.

**Why:** This keeps project execution isolated while preserving a single place to compare priorities and track the portfolio.

**Alternatives considered:** A single monorepo for all side projects; managing each project independently with no portfolio layer.

**Revisit when:** The portfolio grows enough to justify a custom automated dashboard or orchestration layer.
