# Venture Lab

Venture Lab is the portfolio control center for personal AI projects.

It is not a product code repository. It exists to capture ideas, prioritize projects, track portfolio health, and standardize how projects move from idea to validation to build to launch.

|---|---|---|---|
| Digital You | MVP Definition | Jinqiudong/digital-you | UX, progress tracking, physical-performance analysis |

## Portfolio Lifecycle

IDEA → RESEARCH → VALIDATE → BUILD → LAUNCH → GROW

Alternative outcomes: PARKED / KILLED

## What belongs here

- Idea backlog
- Cross-project priorities
- Portfolio status and milestones
- Decision logs
- Validation notes
- Shared project workflow standards
- New-project kickoff templates

## What does not belong here

- Product source code
- Product-specific tests
- Product-specific CI
- Product-specific deployment configuration

Those stay in each product repository.

## Operating Model

Each product repository owns its own:

Issue → Branch → Implementation → PR → CI → Review → Merge → Deploy

Venture Lab provides the portfolio-level view across those repositories.
